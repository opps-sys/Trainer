# Тренажёр по тригонометрии (10 класс) — SPA на React

Интерактивное учебное веб-приложение по теме **«Тригонометрия: значения и тождества»** для учащихся 10 класса.

## Функциональность

- Маршрутизация SPA (`react-router-dom`):
  - `/` — список задач с фильтрацией по предмету, теме, уровню и поиску (параметры хранятся в URL, например `/?level=2&topic=Формулы+приведения`), таймер и генератор индивидуальных вариантов;
  - `/task/:id` — отдельная страница задачи;
  - `/exam` — режим «Контрольная» (5 случайных задач без подсказок, общий таймер, итоговая таблица и отметка);
  - `/stats` — сводная статистика по темам, `<progress>`, сброс прогресса и экспорт в CSV;
  - `/about` — описание проекта, инструкция для учителя, сведения о хранении данных;
  - `*` — страница 404.
- Светлая и тёмная тема оформления (переключатель в шапке, сохранение в `localStorage`).
- Защита от сбоев рендера (`ErrorBoundary`) и от некорректного JSON / ошибок сети.

## Команды запуска и сборки

```bash
npm install      # установка зависимостей
npm run dev      # сервер разработки (http://localhost:5173)
npm run build    # сборка production-версии в dist/
npm run preview  # локальная проверка собранной версии dist/
```

## Источники задач

Учебное пособие «Алгебра и начала анализа» для 10 класса общеобразовательных учреждений Республики Беларусь.

## Этапы разработки (лабораторные работы 1–15)

- **ЛР 1–5:** семантическая HTML5-вёрстка, медиа, таблицы, формы, доступность.
- **ЛР 6–7:** CSS-переменные, светлая/тёмная тема, Flexbox, Grid, адаптивность, стили печати.
- **ЛР 8–9:** логика проверки ответов (`check.js`), структура банка задач (`tasks.json`), генератор индивидуальных вариантов.
- **ЛР 10–11:** программная отрисовка DOM через `<template>` и `DocumentFragment`, делегирование событий, `localStorage`, загрузка через `fetch`, экспорт в CSV.
- **ЛР 12–14:** перенос проекта на Vite + React, хуки (`useState`, `useEffect`, кастомные хуки), архитектура (`lib`, `hooks`, `context`, `components`), `ErrorBoundary`, мемоизация.
- **ЛР 15:** маршрутизация SPA (`react-router-dom`), фильтры в URL, режим «Контрольная», генератор вариантов в интерфейсе, аудит качества и доступности, сборка и публикация.
